# 🦠 Análisis de Malware e Ingeniería Reversa

Este trabajo documenta el análisis estático y dinámico de un ejecutable sospechoso basado en una versión modificada de PuTTY. El objetivo fue identificar modificaciones en el binario, analizar su comportamiento, detectar mecanismos de ejecución y determinar el tipo de malware mediante distintas herramientas de análisis.

## Puntos Clave del Proyecto
* **Análisis Estático**: Inspección de ejecutables, identificación de arquitecturas, strings, imports, secciones y estructuras internas.

* **Análisis Dinámico**: Monitoreo de procesos, memoria, modificaciones del sistema y comportamiento de archivos durante su ejecución.

* **Ingeniería Reversa**: Inspección y reconstrucción de código mediante herramientas de desensamblado y análisis de binarios.

* **Análisis de Red**: Identificación de conexiones, tráfico sospechoso y mecanismos de comunicación utilizados por malware.

* **Técnicas de Malware**: Estudio de persistencia, ofuscación, ejecución de payloads y mecanismos de acceso remoto.

* **Detección de Amenazas**: Identificación de indicadores de compromiso (IOC) y desarrollo de reglas YARA para la detección de archivos sospechosos.
